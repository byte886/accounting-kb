# ADR-002：选择H.265 CRF30作为视频压缩标准

> **文档类型**：Active（过程记录 — 架构决策记录）
> **日期**：2026-08-27
> **状态**：已采纳
> **决策者**：用户 + AI

## 背景

高顿教育网站的课程视频原始文件较大（每个约1.5-2.5GB，码率1.2-2.6 Mbps），需要压缩以节省存储空间和便于传输。项目需要选择一个合适的视频压缩标准和参数。

## 决策

选择 **H.265 (HEVC) + CRF 30 + preset fast** 作为视频压缩标准。

**完整参数**：
```bash
ffmpeg -i input.mp4 \
  -c:v libx265 -crf 30 -preset fast \
  -c:a aac -b:a 96k \
  -tag:v hvc1 -movflags +faststart \
  output.mp4
```

## 备选方案

| 方案 | 优点 | 缺点 | 压缩比 |
|------|------|------|--------|
| H.264 CRF 28 | 兼容性好，编码快 | 压缩率低，文件大 | 约4:1 |
| **H.265 CRF 30** | **压缩率高，质量可接受** | **编码较慢，部分旧设备不支持** | **约8:1** |
| H.265 CRF 28 | 质量更好 | 文件较大 | 约6:1 |
| AV1 | 压缩率最高 | 编码极慢，兼容性差 | 约10:1 |

## 决策理由

1. **压缩率**：H.265比H.264压缩率高约40-50%，2.5小时视频从1.7GB压缩到约200MB
2. **质量**：CRF 30在课件场景下文字清晰、头像略糊但不影响学习，用户验证通过
3. **兼容性**：hvc1标签确保Apple设备（iPhone/Mac）可原生播放
4. **编码速度**：preset fast在20核CPU上约10倍速，每个2.5小时视频约15分钟
5. **音频**：AAC 96kbps在人声场景下清晰，文件小

## 后果

### 正面
- 存储空间节省约87.5%（1.7GB → 200MB）
- 上传百度网盘速度更快
- 本地和网盘存储空间需求大幅降低

### 负面
- 编码需要时间（每个视频约15分钟）
- 部分非常旧的设备可能不支持H.265
- 头像清晰度略有下降（但不影响学习）

## 验证

- 2026-08-27：用户验证CRF30压缩质量，确认文字清晰、声音清楚、体积可接受
- 压缩后视频：约200MB / 2.5小时，码率约184 kbps
- 已用于税法01、开班典礼、会计基础必修等课程的视频压缩
