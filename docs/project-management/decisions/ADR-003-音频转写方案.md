# ADR-003：选择FunASR SenseVoiceSmall作为音频转写方案

> **文档类型**：Active（过程记录 — 架构决策记录）
> **日期**：2026-08-28
> **状态**：已采纳
> **决策者**：用户 + AI

## 背景

课程视频需要将音频转写为文字，作为知识库的内容来源。需要选择一个准确、高效、低成本的音频转写方案。

## 决策

选择 **FunASR SenseVoiceSmall + fsmn-vad** 作为本地音频转写方案。

**技术栈**：
- 模型：FunASR SenseVoiceSmall（中文语音识别）
- VAD：fsmn-vad（语音活动检测）
- 运行环境：本地Python虚拟环境（.venv-transcribe）
- 硬件：Mac Studio（20核CPU / 128GB内存）

## 备选方案

| 方案 | 优点 | 缺点 | 成本 | 准确率 |
|------|------|------|------|--------|
| OpenAI Whisper (large) | 准确率高，多语言 | 本地运行慢，需要GPU | 免费（本地） | 高 |
| faster-whisper | 比Whisper快 | 仍需较长时间 | 免费（本地） | 高 |
| **FunASR SenseVoiceSmall** | **中文准确率高，速度快，轻量** | **主要支持中文** | **免费（本地）** | **高** |
| 阿里云语音识别 | 准确率高，有标点 | 需要API调用，有费用 | 约10-20元/小时 | 高 |
| 讯飞语音识别 | 中文准确率高 | 需要API调用，有费用 | 约15-25元/小时 | 高 |
| 得到大脑会员 | 集成度高 | 35元/月，可能有调用限制 | 35元/月 | 中高 |

## 决策理由

1. **成本**：完全本地运行，免费，预计可节省数百元API费用
2. **中文准确率**：SenseVoiceSmall针对中文优化，在课程场景下准确率高
3. **速度**：在Mac Studio上约5-10倍速，2.5小时视频约15-30分钟
4. **隐私**：音频不上传云端，数据安全
5. **可定制**：可以后处理添加标点、分段、说话人分离等

## 后果

### 正面
- 零成本，可批量处理所有课程视频
- 数据隐私有保障
- 转写速度可接受

### 负面
- 需要本地安装和配置环境（.venv-transcribe）
- 标点和分段需要后处理
- 专业术语可能需要自定义词典
- 虚拟环境迁移到新电脑需要重新创建

## 验证

- 2026-08-28：税法01课程视频转写测试，准确率可接受
- 转写速度：约5-10倍速（取决于音频复杂度）
- 已用于税法01、开班典礼等课程的音频转写
